# Elite Live Presence v1

## Principle
The Hub feels alive without becoming the live engine for every sport.

## Elite Core stores
- compact event card
- event status and time
- universal labels
- follow state
- deep-link to the sport

## The sport stores
- simulation
- scoring
- detailed live state
- play-by-play / telemetry / fight detail / leaderboard detail
- sport-specific presentation

## Following
Core can eventually notify followers when an event starts, becomes final, changes schedule, or involves one of their careers.

## Identity examples
Baseball publishes games. Racing publishes practice, qualifying and races. MMA publishes cards and bouts. Golf publishes tournaments and rounds. Team sports publish fixtures and scores. Tennis publishes draws and matches.
