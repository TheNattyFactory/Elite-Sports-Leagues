# Elite Public Profile v1

## Purpose
A member's public Elite identity is the cross-sport historical page for their entire time in the ecosystem.

## Sections
- display name / username
- member-since date
- Legacy total
- optional bio
- optional banner/title
- Career Passport
- Trophy Room
- public activity/history feed

## Important rule
Public profiles show sport summaries, not editable sport data.

Clicking a career should eventually deep-link into that sport's own public athlete page.

## Privacy
Profiles and activity need user-controlled visibility. Future controls should include:
- public profile on/off
- activity feed on/off
- friends-only activity
- hide selected careers
- block/report integration
