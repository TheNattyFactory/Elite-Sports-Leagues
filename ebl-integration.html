ELITE BASEBALL LEAGUE

Elite Core Integration Guide

1. Link an existing EBL account

POST /api/integrations/baseball/link

{
  "external_user_id": "CURRENT_EBL_USER_ID",
  "external_username": "CURRENT_EBL_USERNAME",
  "role": "PLAYER"
}

2. Hub sends the player to Baseball

GET /api/gateway/enter/baseball

The Hub creates a one-time token and redirects to the EBL entry URL.

3. EBL consumes the token

POST ELITE_CORE_URL/api/gateway/consume

{
  "sport": "baseball",
  "token": elite_token
}

4. EBL restores its own session

external_account.external_user_id
→ load existing EBL user
→ create normal EBL session
→ redirect to EBL home

Ownership boundary

Elite Core:
identity / Hub / cross-sport services

EBL:
players / coaches / commissioner auth
franchises / rosters / games / stats
contracts / standings / awards
