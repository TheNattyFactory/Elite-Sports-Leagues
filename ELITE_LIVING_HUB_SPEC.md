# Elite Living Hub v1

## Purpose
The Hub is not a generic menu. It is the personalized front page of the Elite Sports universe.

## Personalized modules
- Continue Career
- Your Sports
- Legacy summary
- unread notifications
- friends summary
- Trophy Case
- cross-sport news
- Elite activity
- sport launcher
- global ticker

## Future live-event modules
Individual sports may publish upcoming or active events:
- Baseball: next game / live Gamecast
- Racing: race weekend / qualifying / live race
- Basketball: next matchup
- Football: game week
- Hockey: next game
- Soccer: fixture / table movement
- MMA: upcoming fight card
- Golf: current tournament / tee time
- Tennis: current draw / next match

The Hub displays those summaries, but clicking them enters the sport's own presentation.

## Rule
The Hub should answer three questions immediately:
1. What is happening in my careers?
2. What is happening across Elite Sports?
3. Where do I want to go next?
